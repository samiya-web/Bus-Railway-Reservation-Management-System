# Bus and Railway Reservation Management System

## Introduction

The Bus and Railway Reservation Management System is a C-based group project developed by BCA 3rd Semester students. The main purpose of this project is to manage passenger reservations for bus and railway services in a simple and efficient way.

The system allows users to book reservations, display reservation details, search for a reservation, sort reservations according to fare, and manage reservation records using basic Data Structures and C programming concepts.

## Objectives

- To develop a simple reservation management system using C.
- To manage passenger and reservation details.
- To provide searching and sorting functionality.
- To understand the practical use of Data Structures.
- To develop a basic real-world application as a group project.

## Features

- Book a new reservation
- Display all reservations
- Search reservation by ID
- Sort reservations by fare
- Add reservation records using Linked List
- Display Linked List records
- Supports Bus and Railway reservations

## Technologies Used

- C Programming
- Data Structures
- Arrays
- Structures
- Linear Search
- Bubble Sort
- Linked List
- Dynamic Memory Allocation

## How to Run

1. Download or clone this repository.
2. Open the `.c` file in a C compiler or IDE.
3. Compile the program.
4. Run the program.
5. Select options from the menu to manage reservations.

## Data Structures Used

### Array
Used to store and display reservation records.

### Linked List
Used to dynamically store reservation records.

### Linear Search
Used to search for a reservation using the Reservation ID.

### Bubble Sort
Used to sort reservations according to fare.

## Conclusion

The Bus and Railway Reservation Management System demonstrates how C programming and basic Data Structures can be used to develop a simple real-world application. This project helped us understand arrays, structures, searching, sorting, linked lists, and dynamic memory allocation through practical implementation.
